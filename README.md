# `desktop-plus` Homebrew Tap

This is a Homebrew Tap that provides the `desktop-plus` cask, a fork of GitHub Desktop with extra features and improvements.

## How do I install this package?

```sh
brew install desktop-plus/tap/desktop-plus
```

Or add the tap to install packages directly from it:

```sh
brew tap desktop-plus/tap
brew install desktop-plus
```

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "desktop-plus/tap"
brew "desktop-plus"
```
